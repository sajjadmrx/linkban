# Support & Donate ☕

**Linkban (لینکبان)** is a free, open-source, and offline-first project built with care to provide a calm, distraction-free link assistant for everyone.

There are **no ads**, **no paid tiers**, and **no user data collection**. If you find Linkban helpful and want to support its ongoing development, maintenance, and future features, any support is genuinely appreciated!
